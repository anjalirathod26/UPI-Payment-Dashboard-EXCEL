## 📊 Project Overview

The **UPI Payment Dashboard** is an Excel-based data analysis and visualization project designed to analyze UPI transaction data.

The dashboard provides insights into transaction volume, transaction amounts, cashback, payment methods, UPI applications, customer demographics, merchant categories, transaction status, risk scores, and suspected fraudulent transactions.

## 🎯 Objectives

- Analyze UPI transaction patterns.
- Monitor transaction volume and transaction value.
- Compare different UPI applications.
- Analyze customer demographics.
- Identify popular merchant categories.
- Analyze transaction success and failure.
- Monitor cashback and transaction fees.
- Identify potentially fraudulent transactions.
- Present insights through an interactive Excel dashboard.

## 📈 Dashboard Analysis

### UPI Application Performance

Compare transaction activity across UPI applications such as PhonePe, Google Pay, Paytm, Amazon Pay, and Cred Pay.

### Geographic Analysis

Analyze transaction activity by state and city.

### Customer Analysis

Analyze customer behavior based on age group, gender, and device OS.

### Merchant Analysis

Analyze transaction trends across merchant categories such as Grocery, Food & Dining, Education, Healthcare, Fuel, Shopping, Entertainment, and Recharge & Bills.

### Transaction Analysis

Analyze P2P transactions, P2M transactions, bill payments, online shopping, payment modes, and transaction status.

### Fraud & Risk Analysis

Use risk score, suspected-fraud indicators, transaction status, and failure reasons to identify potentially risky transaction patterns.
